# Code of Conduct

## Overview

This repository is maintained as part of the **Arx Project** and provides access to official emulator releases.

By downloading, using, or interacting with this project, users are expected to respect the rules and restrictions outlined below.

## Reverse Engineering & Modification

The emulator is distributed as a precompiled executable (`.exe`). Its source code is not publicly available at this time.

Unless explicitly authorized by the copyright holder, the following activities are prohibited under the project's usage rules:

- Reverse engineering, decompiling, or disassembling the executable.
- Attempting to extract, reconstruct, or recover the original source code.
- Modifying, patching, or tampering with the executable.
- Circumventing licensing mechanisms, security measures, or integrity checks.
- Redistributing modified or unauthorized versions of the emulator.
- Claiming ownership of the emulator or its components.

These restrictions apply to the extent permitted by applicable law.

## Official Releases

Executable files are distributed through the repository's official GitHub Releases section.

- Only releases published by the repository maintainers are considered official.
- Modified or repackaged executables must not be presented as official releases.
- Unauthorized redistribution or commercial use is not permitted.
- Users are responsible for understanding the risks associated with executing third-party software.

## Community Conduct

Users interacting with this repository are expected to behave respectfully.

Harassment, threats, impersonation, spam, malicious file distribution, and abuse of repository features are not tolerated.

## Support & Maintenance

This project is provided **as-is**, without warranties or guaranteed support.

The maintainer is not obligated to provide technical assistance, troubleshoot issues, or respond to requests.

Updates will only be provided while the **Arx Project** remains active. Once discontinued, this repository will become a public archive with no further maintenance or support.

## Enforcement

Violations of these rules may result in restricted participation, removal of comments or contributions, or other actions permitted by GitHub's policies.
