# Security Policy

## Supported Versions

This project is maintained on a best-effort basis while the **Arx Project** remains active. Security updates, patches, and fixes may be released at the developer's discretion.

| Version | Supported |
| ------- | --------- |
| Latest Release | ✅ |
| Older Releases | ❌ |
| Archived Releases | ❌ |

Once the Arx Project is discontinued, this repository will become a **public archive**. No further security updates, patches, or maintenance will be provided.

## Reporting a Vulnerability

If you discover a security vulnerability within this emulator, please report it responsibly.

For security-related information, refer to the official Arx Project resources:

- **Security:** https://getarx.nl/security
- **Website:** https://getarx.nl
- **Legal:** https://getarx.nl/legal

Please avoid publicly disclosing vulnerabilities before they have been reviewed.

### Response & Support

This project is provided **as-is**, without any guarantee of security support or vulnerability resolution.

- **Response Times:** No guaranteed response times are provided.
- **Security Fixes:** Vulnerabilities may be addressed at the developer's discretion.
- **Unsupported Versions:** Older releases will not receive security patches.
- **Disclosure:** Reports may be acknowledged, accepted, or declined without further explanation.

Submitting a vulnerability report does not guarantee a response, investigation, or fix.

## Disclaimer

The developer assumes no responsibility for damages, security incidents, or misuse resulting from the use of this emulator.

Users are responsible for understanding the risks associated with running or modifying this software.

**Security maintenance will end permanently once the Arx Project is discontinued and this repository is archived.**
